# 像素雪票本 ⛷

一个像素风的小 App，帮你查**奥地利、瑞士、法国**雪场的雪票价格，顺便记录你这个雪季滑了多少天、花了多少钱。

👉 **打开：https://yinhanghagn.github.io/pixel-ski/**

不用注册，不用下载，打开就能用。

---

## 装到手机桌面

装好以后和普通 App 一样从桌面点开，在山上没信号也能用。

- **iPhone**：用 **Safari** 打开上面的网址 → 点底部的「分享」按钮 → 选「添加到主屏幕」。
- **安卓**：用 **Chrome** 打开 → 点页面上的「安装」，或者右上角菜单 →「安装应用」。

## 能做什么

### 🎟 查雪票价格

- 选一个日期，就能看到每个雪场当天的票价，可以从便宜到贵排序。
- 除了一日票，还能查 **2–7 天的多天通票**（在「一日票」下拉框里切换）。
- 点开一个雪场，能看到它整个雪季的**价格日历**：每个日期下面直接写着当天的票价，哪几天贵、哪几天便宜，一眼就看出来。
- **搜索不用记全名**：点一下搜索框就有热门雪场；输入中文（比如“索尔登”“采尔马特”）、村镇名（比如“St. Anton”）、地区或国家（比如“蒂罗尔”“瑞士”“冰川”）、或者拼错几个字母，都会弹出相近的雪场。
- **官网购票**：搜索联想和雪场详情里都有「官网购票 ↗」，一点就跳到雪场官网，很多雪场在官网提前买更便宜。
- 还没开季的雪场会显示开季日期和开季后的票价；季初大部分雪场没开时，可以一键跳到大部分雪场开门的那个周末。

### 🐧 记录我的雪季

第一次打开「我的雪季」，选一种方式：

- **我买了季票**：每滑一天记一笔，App 会按当天的票价算你“省”了多少钱。小企鹅会往山顶爬，爬到山顶就是**回本了**！
- **没季票，只想记录**：每滑一天盖一个雪花章，集满解锁徽章，还能看到一共花了多少钱、最常去哪个雪场。也可以填一个季票价格，看看“如果买季票划不划算”。

记录的时候可以选：

- **单日票**：记一天。
- **多天通票**：比如一张 6 天票，记一次就算 6 天，金额按整张票算。

金额会按那天的门市价**自动填好**，如果你在网上买得更便宜，改成实际价格就行。瑞士雪场的瑞郎价格会自动换算成欧元。

## 记录存在哪里？

你的滑雪记录**只存在你自己的手机里**，不会上传到任何地方，别人也看不到。

⚠ 所以换手机、或者清理浏览器数据之前，记得先备份：
「我的雪季」页面最下面 →「备份与恢复」→「导出备份」，把文件存到「文件」App 或网盘里。到新手机上点「从备份恢复」就回来了。

## 价格说明

- 显示的是**成人门市价**（在缆车售票处买的价格）。很多雪场在官网提前买会更便宜。
- 有些雪场用的是**动态定价**（价格每天变，越早买越便宜），这种雪场只显示“动态价”和大概的起步价。
- 价格每周会自动核对更新一次（由 Codex 查询、人工审核后发布），但还是可能有出入，**出发前请以雪场官网为准**。
- 每个价格的来源列在 App 页面最下方。

## 发现问题？

价格不对、少了你常去的雪场、或者有什么好点子，欢迎在 GitHub 上[提一个 Issue](https://github.com/yinhanghagn/pixel-ski/issues)。
